1. Missing Content-Security-Policy Header

A05:2021 – Security Misconfiguration

Security Header Missing

http://httpbin.org

High

7.0 / 10.0

HeadersScanner

2026-08-23 14:05:37.739324

The Content-Security-Policy (CSP) header is absent. CSP is a critical defense-in-depth mechanism that mitigates Cross-Site Scripting (XSS), data injection, and other code injection attacks by restricting which resources the browser is allowed to load. The X-Frame-Options header is not set. Without this header, the page can be embedded in an iframe on a malicious site, enabling clickjacking attacks where users are tricked into clicking unintended UI elements. The X-Content-Type-Options header is missing. Without nosniff, the browser may MIME-sniff responses, potentially treating uploaded files as executable scripts and enabling drive-by download attacks. The HSTS header is absent. Without HSTS, users who type the URL without https:// or follow HTTP links will connect over unencrypted HTTP first, exposing them to man-in-the-middle attacks before any redirect occurs. The Referrer-Policy header is not set. Without it, the browser sends full referrer URLs to third-party sites, potentially leaking sensitive URL paths, query parameters, or internal endpoints. The Permissions-Policy header is absent. Without it, the browser allows access to powerful features like camera, microphone, and geolocation by default on this origin.

Header 'Content-Security-Policy' not present in HTTP response from httpbin.org | Header 'X-Frame-Options' not present in HTTP response from httpbin.org | Header 'X-Content-Type-Options' not present in HTTP response from httpbin.org | Header 'Strict-Transport-Security' not present in HTTP response from httpbin.org | Header 'Referrer-Policy' not present in HTTP response from httpbin.org | Header 'Permissions-Policy' not present in HTTP response from httpbin.org
Add the missing security headers to all HTTP responses: X-Frame-Options, X-Content-Type-Options, Content-Security-Policy, Strict-Transport-Security, Referrer-Policy.
